# Analyst System — Live Cockpit (June 2026)

**What it is & why it matters** — A single **decision surface** that unifies the entire [[Global Macro Brain]] into one self-contained artifact: **macro regime → trade decisions → positioning → Fed → framework**. It turns the wiki's analysis and the systematic engine into *timely, actionable* calls. File: `analyst system/Global Macros Analyst System.html`; builder `tools/build_analyst_system.py`; refresh `refresh_analyst.ps1`. **Real data (FRED + Yahoo + CFTC), no fabrication.**

## What's on it
1. **Decision Desk** — current regime + stance, **book tilt**, **top trades now** ranked by conviction w/ *regime-fit*, a **Growth–Inflation quadrant map** (12-mo trail), a **regime-playbook-vs-actual-stance** check, **risk & execution trade tickets** (vol stop / 1%-risk size / 2R target), and a **"What changed"** trigger feed (signal flips + COT extremes).
2. **Endo / Exo Macro Bias** — the framework's signature scoring: **US Endogenous +36** (live Explorer Score-Engine card, −150…+160 across 17 drivers, state "Inflationary overall"; the June build read +27 and the 2026-07-03 template refresh +35/+29) and **AUD/USD Exogenous +2 engine / −4 workbook** (the cockpit engine's exo is the automated template, which re-scored −2 → +2 "NEUTRAL AUD/USD" and was re-run unchanged on 2026-09-24 (it read −6 in June–July); LOW-conviction short on the −4 Explorer workbook card only; the AU and UK endo cards read +24 and +27 on the **2026-09-24** Explorer build — AU was +34 in the 2026-09-08 and 2026-09-11 log entries, when the AU-vs-US endo differential was near-neutral; the automated FRED template holds US endo **+19**) from the [[The Global Macros Framework|endo/exo]] Excel templates; **plus a live cross-country endo scoreboard** (cockpit engine's own scale, unchanged since the 2026-09-19 build and re-read from the cockpit build on disk — US +17, EU +15, UK +13, Canada +9, Australia +10, **Japan +40**, **China −58**, Asia −15, superseding the US +18, UK +12, Canada +6, Japan +39, China −57, Asia −14 this page had carried since the 2026-06-20 build (US corrected +8 → +18 on 2026-06-21; see [[Log Archive 2026-06 to 2026-07]]) — distinct from the workbook rubrics above) computed from FRED-OECD drivers (`tools/endo_scores.py`) — captures China's deflation and Japan's rate-normalization reflation. A **FX carry exo table** (`endo_scores.exo_majors()`) translates this into directional FX calls for the majors from the nominal carry differential (LONG AUD +23, SHORT JPY −79 / EUR −60 / CAD −51, GBP −4 neutral), completing the endo → exo → trade flow. (US/EZ CPI current; every other economy's CPI, Australia's included, is free-FRED OECD data that lags ~12 months — disclosed in-app. The DBnomics AU CPI (OECD 2026-Q1 4.05%) and RBA D3 M3 (+7.8%) fetched on 2026-07-04, and the true BoE M4, belong to the AU and UK workbook cards, not this engine; on the 2026-09-24 Explorer build the AU card still shows its CPI and M3 drivers as STALE, scored 0 — the duplicate-workbook cause is in the 2026-09-24 read below; the exo uses current nominal carry, not a CPI-dependent real rate.)
3. **Regime Scoreboard** — [[Leading Indicators|Leading]] / [[Coincident Indicators|Coincident]] / [[Lagging Indicators|Lagging]] / Liquidity composites, 16 live indicators, Net-Liquidity + Inflation charts, and a **Rates & Risk panel** (2Y/10Y/30Y, real 10Y, breakeven, HY spread, VIX + risk tone).
4. **Cross-Asset Signals** — the full 23-instrument book from [[Trading System - Backtest (June 2026)|the systematic engine]] + a **ranked momentum bar**.
5. **Positioning** — [[Commitment of Traders (COT)|CFTC COT]] net-spec, 3y percentile, weekly change, crowding lean, + a **percentile bar chart**.
6. **Track Record & Honest Read** — backtest KPIs, audit-corrected caveats (bond-sleeve driver, shorts a Sharpe drag, forward ~0.4–0.5), and **equity / drawdown / sub-period charts**.
6. **Framework & drill-downs** — the [[The Global Macros Framework|method]] in brief + links to the detailed dashboards.

## "Real-time" — the honest mechanics
A self-contained HTML file **cannot poll FRED from the browser** (no CORS headers), so freshness = **build-time live data + an age indicator** (green < 36h) + **one-command refresh** (`refresh_analyst.ps1`). Automatic updates can be wired via a Windows Scheduled Task. The cockpit is a **timing/sizing overlay** on a discretionary macro view — not autopilot. *Educational; not investment advice.*
