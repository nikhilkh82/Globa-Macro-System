# Global Macro Trading Deck (July 2026)

**What it is** — The trading-focused macro deck: historical charts for **indexes (9 countries), FX majors (9 pairs incl. DXY), commodities (oil/gold/silver/copper), FX volatility and commodity volatility**, with **weekly panels for context and daily 6-month panels for data releases**, a rules-based **macro-regime classifier** (Goldilocks / reflation / stagflation / hard landing / liquidity shock) and a **risk-regime classifier** (vol complex + USD + credit). Artifact: `macro deck/Global Macro Trading Deck.html`; raw pulls snapshot to `macro deck/raw/<date>/` so **prior vintages are never overwritten**; decision-log template at `macro deck/decision_log.md`.

**Institutional extension (same day):** consolidated into a 13-section framework — added **cross-asset volatility** (VIX/VXD/VXN/MOVE + inflation uncertainty via breakeven realized vol), **credit & sovereign risk** (Moody's Baa/Aaa 20y anchor + HY/BBB/IG OAS + euro periphery spreads + bond-spread-implied sovereign default-probability ranking — CDS proxy, disclosed), **equity-credit & sector risk** (computed 'credit-VIX' proxy, VIX×HY scatter map, 11-sector equity-derived stress table), **inflation-adjusted spreads & correlations** (HY−breakeven cushion, HY/VIX/VXD correlation heatmaps, **live Cboe COR implied-correlation term structure**), **swaps & derivatives** (CMT curve snapshot + slopes as the swap-curve proxy, multi-currency 10y panel, TIPS breakevens as the inflation-swap proxy; SOFR swaps/xccy basis/swaption surfaces disclosed as licensed with MOVE the swaption proxy), and a **trading framework** (5-regime playbook, event-day checklist, source map). Styled light-page/dark-terminal-charts with sticky section nav.

## Architecture
- **Regime board** — growth composite (ISM, global PMI, payrolls-momentum z's) × inflation composite (CPI YoY, core 3m-saar, core PCE z's) → five-regime map with explicit thresholds; 5-signal stress checklist (VIX/MOVE/FX-vol percentiles, HY OAS z, USD 1m squeeze) → RISK-ON/NEUTRAL/RISK-OFF/LIQUIDITY SHOCK.
- **Momentum layer** — 23-country PMI panel (from the maintained S&P Global workbook), US inflation momentum, rates/real-yields/curve/MOVE, broad USD + HY OAS.
- **Asset panels** — weekly 5y and daily 6m normalized panels + a momentum matrix (1w/1m/3m/1y, 50/200d trend state, 1y percentile) across all 22 instruments.
- **FX-vol add-on** — Cboe's FX-vol indices are ALL discontinued (EUVIX/JYVIX †2022, BPVIX †2023, EVZ †2025) → live gauge is **20-day realized vol** per pair with archival implied overlaid; carry-unwind / policy-event / intervention playbook.
- **Commodity-vol add-on** — **OVX, GVZ and VXSLV** (VXSLV live from Cboe's own CDN incl. intraday range; FRED's copy died 2022): level, 1d/1w change, intraday range, 1m/1y percentiles, **implied ÷ 20d realized** with a mechanical sizing rule (IV/RV >1.25 & rising → widen stops / cut notional), and the **VXSLV−GVZ silver premium**.
