# Session Records

Per-session provenance for the Global Macro Brain — a human-readable record of what each working session changed and why. Complements the terse, append-only [[log]] (which is the canonical greppable changelog) with fuller narrative, decision rationale, and follow-up tracking.

> **Why this exists.** The [[log]] captures *what* happened in one line per op; these records capture *what + why + what's left*, so a future session (or reviewer) can reconstruct the reasoning without re-reading the whole chat.

> **Status (2026-09-19): retired.** Only one session record was ever written (2026-06-19). From then on each session's what / why / what's-left went into the dated entries of [[log]] (and its archive), which is what later sessions actually read. This page stays as the index of that one record; do not start new per-session files.
